001 The work

Five things we designed, built, and still operate.

Where the code is public the link goes to the repository. Where it isn't, the link goes to the running product.

Entry 01 / 05

KaziLaw

Tanzanian employment law, with citations

Free question-and-answer over the Employment and Labour Relations Act, plus a compliance check that walks an employer through what the Acts actually require. Every answer cites the section it came from, so a reader can verify it against the law rather than trust the model.

KaziLaw is not a law firm and does not give legal advice. It is Tanzanian labour law, organised.
Live Next.js Postgres + pgvector Retrieval over statute
kazilaw.com ↗
Entry 02 / 05

Dino IG

A dinosaur chat app for children

Shipped on the Apple App Store and built contract-first: the OpenAPI schema generates the typed client, so the app and the API cannot quietly drift apart. Identity is derived on the device instead of collected, so a child never creates an account.

Live · App Store React Native OpenAPI → typed client No accounts
github.com/sugarshaneaz/DinoIG ↗
Entry 03 / 05

Chuma

Training, written for East Africa

Not translated into the region but written for it: Swahili first, bodyweight-first programming for people without a gym, and East African food in the nutrition side. Rotating trainer-led programs, set-by-set logging, and a licensed exercise library served from our own infrastructure instead of somebody else's quota.

In build React Native / Expo Swahili-first Self-hosted media
Its programming engine is open source ↗
Entry 04 / 05

Sema & Sema-API

Customer-facing AI with the guardrails written down

Each industry pack declares what the assistant must never invent and when it has to hand off to a person — the pharmacy pack refuses dosage, drug interactions and diagnosis outright. Blank onboarding fields are fed back into the prompt, so the model is told what it does not know instead of filling the gap itself.

Open source TypeScript Knowledge packs Escalation rules
github.com/sugarshaneaz/Sema-API ↗
Entry 05 / 05

routine-engine

Deterministic program generation

The training-program generator extracted from Chuma and released on its own. Given a catalogue and a configuration it produces a full rotating program deterministically — same input, same program — with a test suite that asserts both full coverage where movement patterns exist and graceful degradation where they don't.

Open source · MIT TypeScript Deterministic 25 tests
github.com/sugarshaneaz/routine-engine ↗

002 Infrastructure

We run our own hardware, and our own agents on it.

Two systems we built for ourselves and run in production. Neither is public — this page is the only place they are described.

Internal

OpenClaw

The agent runtime our automation runs on. Long-lived agents with their own memory, scheduled work and tool access, sitting directly on our servers rather than behind someone else's platform — so the jobs keep their state and we keep the logs.

Internal

Hermes

The agent that directs production work: media pipelines, batch generation, and the routine operational jobs that would otherwise be a person copying numbers between systems. It briefs the tools, checks the output and reports what it did.

Servers
Dedicated and virtual hosts we administer ourselves, running 15+ containerised services.
Data
Postgres with pgvector for retrieval, on databases we can back up and inspect.
Inference
Self-hosted image, video and speech models on our own GPU, alongside hosted APIs where they earn their cost.
Operations
Daily reporting automation for a three-location restaurant group: sales digests, cost variance flagging and tax-receipt tracking.
